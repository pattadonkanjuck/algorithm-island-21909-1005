# Algorithm Island — 21909-1005

เกม 2D สำรวจหมู่บ้านขนาดย่อมสำหรับรายวิชาพื้นฐานการเขียนโปรแกรมคอมพิวเตอร์ ทำด้วย Godot 4 และ GDScript โดยภาพฉากและตัวละครต้นแบบวาดจากโค้ดในโปรเจกต์ เพื่อให้เริ่มเล่นและแก้ไขต่อได้โดยไม่ต้องติดตั้ง asset pack

## เปิดโปรเจกต์

1. เปิด Godot 4.7 ขึ้นไป
2. เลือก Import แล้วเลือก `project.godot` ในโฟลเดอร์นี้
3. กด F6 เพื่อรันฉาก หรือ F5 เพื่อรันเกม

ถ้ามี Godot CLI ใน PATH สามารถใช้ `godot --path . --editor` เพื่อเปิดเอดิเตอร์ หรือ `godot --path .` เพื่อรันเกม

## การควบคุม

- WASD หรือปุ่มลูกศร: เดิน
- E หรือ Space: สนทนา/เริ่มบทเรียนเมื่ออยู่ใกล้ศาลาหรือเครื่องมินิเกม
- M: เปิด/ปิดแผนที่
- Esc: ปิดหน้าต่างบทเรียน

## ด่านและเนื้อหา

ด่าน 1 มีคำถาม 5 ข้อเรื่องชนิดข้อมูลและตัวแปร, เงื่อนไข, วนรอบ, อาร์เรย์ และการตรวจแก้โปรแกรม ต้องตอบถูกครบทั้ง 5 แล้วเดินไปที่ประตูและกด E (หรือเดินชิดประตู) เพื่อเปลี่ยนไปฉากด่าน 2

หน้าเริ่มเกมคือ `scenes/title.tscn` มีปุ่ม Start ก่อนเข้าสู่ด่าน 1 ด่าน 2 เป็น Scene แยกชื่อ `scenes/level2.tscn` ใช้แผนที่วาดจากโค้ด มีตัวละครให้เดินสำรวจ และมีมินิเกมต่อบล็อก 3 ภารกิจ ได้แก่ ลูปนับเลข, หาผลรวมด้วยลูป และตรวจเลขคู่/คี่ เมื่อผ่านภารกิจสุดท้ายจะเข้าสู่ฉากชนะ `scenes/victory.tscn` ซึ่งมีปุ่มเล่นอีกครั้ง

เวอร์ชันความคืบหน้าก่อนการแก้ระบบคะแนนจะเริ่มนับใหม่ เพื่อไม่ให้สถานะเก่าที่อาจบันทึกคลาดเคลื่อนปลดล็อกด่านให้อัตโนมัติ

## เว็บและ GitHub Pages

โปรเจกต์มี Web export preset ใน `export_presets.cfg` และ GitHub Actions workflow ใน `.github/workflows/deploy-pages.yml` เมื่อ push ไป branch `main` workflow จะติดตั้ง Godot 4.7.2 พร้อม export templates, export เกม และเผยแพร่ไป GitHub Pages อัตโนมัติ

ตั้งค่า **Settings → Pages → Source** เป็น **GitHub Actions** แล้ว (ครั้งแรก) เมื่อ push ไป `main` workflow จะ export เกมและ deploy ไป GitHub Pages อัตโนมัติ

## โครงสร้าง

- `project.godot` — ตั้งค่าโปรเจกต์และ input
- `export_presets.cfg` — Web export preset
- `.github/workflows/deploy-pages.yml` — build และ deploy GitHub Pages
- `scenes/world.tscn` — ฉากหลักและตัวละคร
- `scenes/title.tscn` — หน้าเริ่มเกมและปุ่ม Start
- `scenes/level2.tscn` — ฉากด่าน 2 และแผนที่วาดจากโค้ด
- `scenes/victory.tscn` — ฉากจบเมื่อผ่านครบทุกภารกิจ
- `scripts/world.gd` — ด่าน 1, คำถาม, คะแนน และการเปลี่ยนฉาก
- `scripts/level2.gd` — การสำรวจแผนที่และมินิเกมต่อบล็อกของด่าน 2
- `scripts/station.gd` — เครื่องหมายสถานีเขียนโปรแกรมบนแผนที่ด่าน 2
- `scripts/victory.gd` — ฉากชนะและปุ่มเริ่มเล่นใหม่
- `scripts/player.gd` — การควบคุมและภาพตัวละครต้นแบบ
- `assets/reference/` — ภาพแนบอ้างอิงจากผู้ใช้

ภาพอ้างอิงลำดับแผนที่และหน้าตาบล็อกถูกเก็บไว้ใน `assets/reference/` เพื่อใช้เทียบแนวทางเท่านั้น มินิเกมปัจจุบันใช้ปุ่มเลือกบล็อกเพื่อให้รองรับการเล่นบนเว็บและจอสัมผัสได้ง่าย

ภาพใน `assets/reference/` เป็นภาพอ้างอิงที่ผู้ใช้แนบไว้ ฉากกับตัวละครในรุ่นต้นแบบวาดจาก GDScript แยกต่างหาก จึงยังไม่ได้ดึง sprite sheet ในภาพมาใช้เป็นตัวละครจริง

เอกสารหลักสูตรที่ใช้วางหัวข้อ: หลักสูตร ปวช. 2567 สาขาวิชาช่างเทคนิคคอมพิวเตอร์ รายวิชา 21909-1005 ซึ่งระบุหัวข้อภาษาซีและการเขียนโปรแกรมพื้นฐาน โปรดให้ผู้สอนตรวจทานโจทย์และเฉลยก่อนใช้เป็นสื่อประเมินผลจริง
